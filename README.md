# cardiometabolic-risk-prediction

This project explores machine learning approaches for predicting major cardiometabolic conditions including:

- Hypertension (HTN)
- Type 2 Diabetes (T2D)
- Coronary Artery Disease (CAD)

The models were developed using Logistic Regression with preprocessing techniques such as mean imputation, feature scaling, and SMOTE balancing for imbalanced datasets.

## Key Features

- Logistic Regression risk prediction models
- Missing value handling using SimpleImputer
- SMOTE balancing for hypertension dataset
- Risk probability estimation
- Explainable contributing risk factors
- CAD lifestyle “what-if” simulation
## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
